# Memorization Techniques

## Active recall
**Active recall** is an attempt to retrieve information from memory without a prompt before looking at the answer.
The **testing effect** is a phenomenon in which testing yourself leads to better memory than rereading the same material.
The **illusion of knowing** is the feeling that material has been learned because it seems familiar when reread.

## Spaced repetition
**Spaced repetition** is reviewing material at intervals that grow after each successful recall.
The **Leitner system** is a method of spaced repetition using flashcards sorted into boxes.
1. All new cards go into the first box.
2. A card answered correctly moves to the next box.
3. A card answered incorrectly goes back to the first box.
4. The further the box, the less often it is reviewed.

## Interleaving
**Interleaving** is mixing different topics or types of problems within one study session instead of working through them in blocks.

| | Blocked | Interleaving |
|---|---|---|
| How tasks come | first all of one kind, then another | different kinds mixed together |
| How studying feels | easy | harder |
| Result a week later | remembered worse | remembered better |
